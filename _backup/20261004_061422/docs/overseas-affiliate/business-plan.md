# 海外アフィリエイト事業部（ドル建て収益）— 事業設計書 v0.1

英語圏の訪日旅行者向けに、日本語でしか手に入らない一次情報を英語で整えて出し、旅行系アフィリエイト（ドル建て）で稼ぐ事業の設計書。
運営はAIエージェント組織で回し、人（Keita）の作業時間は**週3時間以内**を目標にする。

> ⚠️ 前提の修正：「完全放置」は今の環境では成り立たない。
> Googleは2024年3月から「AIで量産した低価値ページ」をスパム扱いしていて、手動ペナルティを受けるとサイトごと検索から消える。さらにAI Overviewsで検索からのクリック率が大きく落ちている（後述）。
> 現実的に狙えるのは「放置」ではなく**「仕組みで回して、人は週3時間の判断だけ」**の状態。この文書はそれを前提にしている。

## 1. 前提整理

| 項目 | 事実 | 出典 |
|---|---|---|
| 訪日外国人数（2025年） | 4,268万人（前年比+15.8%、過去最高） | [Travel Voice](https://www.travelvoice.jp/english/international-arrivals-in-japan-exceeded-42-million-in-2025-10-million-more-than-2019) |
| 米国からの訪日客（2025年） | 330万人（前年比+21.4%） | 同上 |
| 訪日客の消費額（2025年） | 9.5兆円 | 同上 |
| Amazon US アソシエイト料率 | 多くのカテゴリで1〜4.5%、一部10% | [AffiliateX](https://affiliatexblocks.com/amazon-affiliate-commission-rates/) |
| Klook アフィリエイト料率 | ツアー・ホテル6.5%、アトラクション5%、eSIM 20%、Cookie 30日 | [Lasso](https://getlasso.co/affiliate/klook/) |
| Airalo（eSIM）料率 | 標準10%、Cookie 30日 | [Airalo公式](https://www.airalo.com/blog/airalo-affiliate-program-faqs) |
| AI Overviewsの影響 | 検索1位のクリック率が34.5%減（Ahrefs、30万キーワード） | [Search Engine Journal](https://www.searchenginejournal.com/impact-of-ai-overviews-how-publishers-need-to-adapt/556843/) |
| Googleのスパムポリシー | 量産した低価値ページは手段（AI・人力）を問わず違反。手動ペナルティあり | [PPC Land](https://ppc.land/scaled-content-abuse/) |

### この事実から言えること
1. **Amazon物販はやめる**。料率1〜4%ではドル建てでも割に合わない。
2. **「Google検索だけに頼るブログ」は構造的に負けている**。流入元を分けること、AIに要約されにくい形（ツール・データ・最新情報）で作ることが必須。
3. **訪日インバウンドは伸びている市場**で、日本に住んでいるKeitaには「日本語の一次情報を読める」という、英語圏の競合が真似できない強みがある。

## 2. 仮説（4パターン比較 → 1つ選ぶ）

| 案 | 中身 | 収益 | 実績 | 時間（自動化） | 判定 |
|---|---|---|---|---|---|
| A. 英語のAmazon物販レビューブログ | ガジェット等の比較記事 | ✕ 料率1〜4% | △ | △ AI量産はペナルティのリスク | 却下 |
| B. 英語のSaaS比較（継続報酬） | ツール比較で継続報酬を狙う | ○ | △ | △ | 競合が最も強い（米国の大手メディアが上位を占めている） |
| C. 金融・VPN・ホスティング | 高単価案件 | ◎ | △ | ✕ YMYL（お金・健康などの分野）扱いで審査が厳しく、新規サイトは上位に出にくい | 却下 |
| **D. 訪日旅行者向けの英語メディア＋ツール** | eSIM／体験ツアー／交通パス／ホテル | ○ eSIM 10〜20% | ◎ 日本在住という信用 | ◎ 一次情報の収集を自動化できる | **採用** |

### 採用：D「Japan Travel × 情報の差（日本語の一次情報）」
- 他の人が持っていない材料：自治体・鉄道会社・観光協会などの**日本語でしか出ていない最新情報**（運休、祭りの日程、混雑、料金改定）を英語にする。
- 収益導線：eSIM（Airalo／Klook eSIM）→ 体験ツアー（Klook／GetYourGuide）→ ホテル（Booking.com／Agoda）→ 交通パス。

### 普通はやらないが勝てる可能性のある案
**「記事」ではなく「無料の計算ツール」を主力にする。**
- 例：「JR Pass vs 個別切符 損益計算機」「旅行日数別eSIM最安比較ツール」「都市別・1日あたりの旅費シミュレーター」
- 理由：①AI Overviewsは計算・比較の操作を代わりにできない ②ツールは被リンクを集めやすい ③データ（料金表）を更新するだけで、記事を書き直す手間がかからない＝自動化と相性がいい。
- 普通やらない理由：最初の開発に手間がかかるから。でもClaude Codeで作れば作る手間はほぼかからない。ここが勝てるポイント。

## 4. 収益モデル（仮説）

### 1件あたりの報酬（仮説）
| 商品 | 平均購入額 | 料率 | 1件の報酬 |
|---|---|---|---|
| eSIM | $20 | 10〜20% | $2〜4 |
| 体験ツアー | $80 | 5〜6.5% | $4〜5 |
| ホテル（3泊） | $450 | 約4% | 約$18 |

### 月$3,000に必要な量（仮説）
- 平均報酬$5/件 → **月600件の成約**
- 外部リンククリックから成約する率5% → 月12,000クリック
- 訪問者が外部リンクを押す率10% → **月12万PV**

### LTV／CAC
- **CAC（1人集める費用）**：広告を使わないのでほぼ$0。固定費はAIツール・サーバー・ドメインで月$100前後（仮説）。
- **LTV（1人から生涯で得る報酬）**：1回の旅行で eSIM＋ツアー2件＋ホテル ＝ 約$30（仮説）。**メールリストに登録してもらえば**、旅行前のチェックリスト配信で成約が重なり、LTVが上がる。
- → メールリストを**Googleに左右されない自社の資産**として最優先で育てる。

## 5. 競争優位性
1. **情報の差**：日本語の一次情報を自動で集めて英語にする仕組み（英語圏の競合はこれを読めない）。
2. **ツール資産**：計算ツールはAIに要約されにくく、被リンクが積み上がる。
3. **E-E-A-T（経験・専門性・権威性・信頼性）**：日本在住の運営者による実地の写真・体験。AIだけで作った量産サイトとの違いを示せる。
4. **流入元が4つ**：Google／Pinterest／YouTube Shorts／メール。1つのアルゴリズム変更で全滅しない。

## 6. スケール戦略（人を増やさずに伸ばす）
- **同じ型を横に展開**：Japan → Korea／Taiwan（同じ仕組みで国を差し替える）。ただし現地の一次情報という強みは薄れるので、Japanで再現性を確認してからにする。
- **言語展開**：英語 → スペイン語・ドイツ語（ツールは翻訳コストがほぼかからない）。
- **データの外販**：更新し続けている料金・日程データをAPIや埋め込みウィジェットとして他の旅行メディアに提供（Phase 3以降の仮説）。

## 8. 法律・規約・税務（先に潰すもの）

| 論点 | 対応 | 出典・備考 |
|---|---|---|
| FTC（米国の消費者保護機関）の開示ルール | 各ページの**リンクより前**に「Paid Link／I earn a commission」を明記。「Commissionable Link」だけでは不十分とされる | [Tricia Meyer](https://www.tricia.me/2023/06/29/ftc-updates-disclosure-guidelines-affiliates-influencers/) |
| Googleの量産コンテンツ規制 | 1ページごとに一次情報 or ツール or 実地の写真のいずれかを必須にする。**AIの文章を量産だけして公開するのは禁止** | [PPC Land](https://ppc.land/scaled-content-abuse/) |
| 米国の源泉徴収 | 米国ASPにはW-8BEN（米国外居住者であることを示す税務書類）を出す。日米租税条約で減免されるのが一般的 | **要確認：各ASPの案内と税理士** |
| 日本の税金 | ドル報酬も円に換算して確定申告。会社員なら副業所得が年20万円を超えたら申告が必要 | **要確認：税理士** |
| 法人化 | 最初は個人事業（開業届）で始める。利益が年数百万円を安定して超えたら法人化を検討 | 目安は税理士に確認 |
| ドルの受け取り | Wise／Payoneerの米ドル口座で受け取り、ドルのまま持つか円にするかを選べるようにする | 各ASPが対応しているか要確認 |
| 各ASPの規約 | Klook・Booking等はメール内にリンクを直貼りすることを禁止している場合がある | 申請時に確認 |

## 10. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| Googleのアルゴリズム変更・AI Overviews | 流入が半減 | 流入元を4つに分ける＋メールリスト＋ツール主体 |
| 量産ペナルティ | サイトが検索から消える | 品質ゲート＋Keitaの承認＋1ページ1つの一次情報 |
| 訪日需要の急減（為替・災害・感染症） | 売上の急減 | Phase 3で他の国・言語に分散 |
| ASPの料率引き下げ・プログラム終了 | 収入減 | 1つのASPに依存しない（同じ商品を2社以上で扱う） |
| 誤情報（運休・料金） | 信用の低下・クレーム | データに「最終確認日」を表示し、自動で再確認する |
| 為替（円高） | 円に換算した額が減る | ドルのまま持つ選択肢を残す |
