## 共通の前提（仮説。確定したら更新）
- 対象業種: **美容室（仮置き）**。変更する場合は両社の CHARTER.md を同時に更新する
- 法人格: 現時点では設立しない。開業届を出す個人事業主で十分（法人設立は初期費用1万円以下の条件に合わない。売上が月20万を安定して超えた時点で再検討）
- 本業の就業規則（副業可否）はKeitaが確認すること

## 運用ルール
1. 外部に出る操作（送信・投稿・公開・契約・決済設定）は必ずKeita承認。各社の `approvals.md` に承認待ちとして積む
2. Keitaの稼働は承認と判断のみ。目標は合計で週3〜5時間
3. 4週時点で両社のKPIを見て、主軸を残すか寄せるか撤退するかを判断する（`decisions.md` に記録）
4. 数字・規約・法令は出典を付けて書く。確認できていないことは「未確認」と明記する
5. 既存ファイルを変更する前は `_backup/日付_時刻/` にコピーする
