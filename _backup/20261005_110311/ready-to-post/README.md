# ready-to-post（そのまま使う素材フォルダ）

**Instagram・Etsyで実際に使うファイルはすべてここに入っている。** スマホに保存して、そのままアップロード・貼り付けすればよい。
台本や設計の文書は `content/` と `docs/` にある（ここには入れない）。

## 中身と使う順番
| 順番 | フォルダ | 中身 | 使い方 |
|---|---|---|---|
| 1 | `01_profile/` | `profile-icon.png`（プロフィール画像）、`profile-text.txt`（名前・自己紹介） | プロフィールを編集するときに使う |
| 2 | `02_reels/` | リール5本分。1本につき `_video.mp4`（動画）、`_cover.png`（表紙）、`_caption.txt`（キャプション）の3つ。ファイル名の先頭が「番号_投稿日」 | R1=10/5、R2=10/6、R3=10/7、R4=10/8、R5=10/9 の朝8時に予約 |
| — | `03_etsy/` | （Etsyの商品画像・PDFが完成したらここに入れる） | Etsyのショップ開設後 |

## リール1本の予約手順
1. 「＋」→「リール」→ `R?_..._video.mp4` を選んで「次へ」
2. `R?_..._caption.txt` の中身を貼る
3. 「カバーを編集」→ `R?_..._cover.png` を選ぶ
4. シェア直前の画面を下にスクロール →「その他のオプション」→「このリール動画を日時指定」をオン → 日時を指定 →「完了」

## ルール（Claudeが守ること）
- 新しい素材は必ずこのフォルダに入れる。サブフォルダは作らず、ファイル名を「番号_投稿日_テーマ_種類」にする（iPhoneのファイルアプリでまとめて選んで保存できるように）
- 投稿が終わったファイルは `02_reels/_posted/` に移す

## iPhoneでの使い方（保存は最初の1回だけ）
1. Claudeから届いた `ready-to-post.zip` をタップ → 共有ボタン →「"ファイル"に保存」→「このiPhone内」→「保存」
2. 「ファイル」アプリ →「このiPhone内」→ `ready-to-post.zip` をタップすると、フォルダに展開される
3. `02_reels` を開く → 右上の「…」→「選択」→ `_video.mp4` と `_cover.png` を全部選ぶ → 左下の共有ボタン →「○項目を保存」→ 全部まとめて「写真」に入る
4. キャプションは、ファイルアプリで `_caption.txt` を開いてコピーする

## 投稿ボード（いちばん楽な使い方）
https://claude.ai/artifact/1cHusyq7bBKLipWPe7eiJb
iPhoneのClaudeアプリで開くと、今日のリールが一番上に開いた状態で出る。「① 動画を保存」→ 共有メニューで「Instagram」または「ビデオを保存」→「② キャプションをコピー」→ Instagramで貼る。
素材が増えたら Claude が `python3 apps/post-board/build.py` でページを作り直して、同じURLに公開する。
