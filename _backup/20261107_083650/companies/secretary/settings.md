# 秘書の設定（公開禁止）

## 作業できる時間帯（2026-11-07 Keita回答）
| 曜日 | 開始 | 終了 |
|---|---|---|
| 月 | 8:00 | 24:00 |
| 水 | 7:00 | 24:00 |
| 火・木・金・土・日 | 9:00 | 24:00 |

- この中で、カレンダーの予定が無い時間に作業枠を入れる。予定の前後15分は移動・休憩として空ける
- 定例: 月21:00〜22:00 ビジコン週次
- 入れない: 遠出の日（例: 函南 11/12〜14）、会食の後、23:30以降
- 朝の確認（10分）: 各曜日の開始時刻。夜の確認（10分）: 23:30。カレンダーに定期予定として入れてある
- 未確認: 本業・授業の時間（カレンダーに無ければ空きとして扱う。ぶつかったら教えてもらう）

## 拠点と移動（2026-11-07 Keita指示）
- 拠点: **千葉県柏市**。場所の指定が無いタスクは「柏」（在宅）
- 外に出るタスク・予定は「場所（住所かエリア）」と「到着したい時刻」をもらう。終了時刻が分かれば帰りも出す
- 自宅→柏駅: 6分（2026-11-07 Keita回答）
- 早め到着: 10分
- 駅から会場まで: 住所が分かれば徒歩分を足す（計算の4つ目の値）。時刻は5分単位で丸める（出発は早め、帰宅は遅め）
- 一度帰る条件: 予定の間が「帰り＋行き＋60分」より長いときだけ柏に帰る。短ければ直行
- 所要時間の表: `travel.md`。計算: `python3 -I scripts/travel_plan.py 日付 "エリア,到着,終了" ...`
- カレンダーには【移動】として、行き・帰りの両方を入れる（既存の予定は動かさない）
- 住所は**カレンダーにだけ**書く。repoにはエリア名だけ（個人宅の住所は書かない）

## 優先度
| 優先 | 条件 |
|---|---|
| P0 | 期限が48時間以内／相手を待たせている／期限切れで無効になる（招待・URL期限） |
| P1 | 収益に直結（売上・契約・お金の出入り） |
| P2 | 実績・信用になる（公開物、人との約束） |
| P3 | それ以外。14日動かなければ捨てる候補 |
同じ優先度なら、期限が近い→工数が小さい順。
