# ready-to-post（そのまま使う素材フォルダ）

**Instagram・Etsyで実際に使うファイルはすべてここに入っている。** スマホに保存して、そのままアップロード・貼り付けすればよい。
台本や設計の文書は `content/` と `docs/` にある（ここには入れない）。

## 中身と使う順番
| 順番 | フォルダ | 中身 | 使い方 |
|---|---|---|---|
| 1 | `01_profile/` | `profile-icon.png`（プロフィール画像）、`profile-text.txt`（名前・自己紹介） | プロフィールを編集するときに使う |
| 2 | `02_reels/R1_2026-10-05_tax-free/` | `video.mp4`、`cover.png`、`caption.txt` | 10/5 朝8時に予約 |
| 3 | `02_reels/R2_2026-10-06_narita/` | 同上 | 10/6 朝8時に予約 |
| 4 | `02_reels/R3_2026-10-07_haneda/` | 同上 | 10/7 朝8時に予約 |
| 5 | `02_reels/R4_2026-10-08_suica/` | 同上 | 10/8 朝8時に予約 |
| 6 | `02_reels/R5_2026-10-09_subway-ticket/` | 同上 | 10/9 朝8時に予約 |
| — | `03_etsy/` | （Etsyの商品画像・PDFが完成したらここに入れる） | Etsyのショップ開設後 |

## リール1本の予約手順
1. 「＋」→「リール」→ `video.mp4` を選んで「次へ」
2. `caption.txt` の中身を貼る
3. 「カバーを編集」→ `cover.png` を選ぶ
4. シェア直前の画面を下にスクロール →「その他のオプション」→「このリール動画を日時指定」をオン → 日時を指定 →「完了」

## ルール（Claudeが守ること）
- 新しい素材は必ずこのフォルダに入れる。フォルダ名は「番号_投稿日_テーマ」
- 投稿が終わったフォルダは `02_reels/_posted/` に移す
