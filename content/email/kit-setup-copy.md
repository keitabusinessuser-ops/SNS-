# メールリスト（Kit）設定用の文章 v0.1

Kit（旧ConvertKit）の無料プランを使う前提。無料で登録者1万人まで、登録ページ（ランディングページ）と登録フォームは無制限（[PassiveKit](https://www.passivekit.com/kit-free-plan/)）。
自動で何通も送るステップメールは有料プランが必要なので、最初は「登録したらチェックリストのPDFが届く」ところまでにする。

## 登録ページ（Landing page）
**見出し**
```
Your first 72 hours in Japan, sorted.
```
**本文**
```
Get the free Japan Arrival Checklist (Tokyo edition):

✓ What to set up before you fly (Visit Japan Web, eSIM, Suica)
✓ Which train to take from Narita or Haneda
✓ The new tax-free rules from Nov 1, 2026 — so you don't lose your refund
✓ 3 numbers to save before you land

One page. Checked against official sources. Free.
```
**ボタン**
```
Send me the checklist
```
**ボタンの下の小さな文字**
```
You'll also get occasional Japan travel tips. Unsubscribe anytime.
```

## メールの最後に必ず入るもの（法律で必要）
- 配信停止のリンク（Kitが自動で入れる）
- **送信者の住所**（米国のCAN-SPAM法で、商用メールには有効な住所が必要。私書箱や、登録済みの私設私書箱でもよい）（[参考](https://mailtester.com/blog/can-spam-physical-address-requirement-po-box/)）
  → 自宅住所を出すと情報漏洩になるので、**住所の出し方はKeitaの承認が必要**（approvals-needed.md のA2）
