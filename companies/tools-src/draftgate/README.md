# draftgate

> **AIが作り、人（運営者）が最終確認と公開をします。** 設計・実装・テスト・READMEの下書きはAI（Claude）が行いました。

AIの下書きを公開・送信する前に、**作業の残骸**が残っていないかを調べるコマンドです。
「【要確認】を残したまま公開した」「『以下のとおりです』が先頭に付いたまま送った」を防ぐ補助です。文体の良し悪しや、内容の正しさは見ません。

- Node.js 標準ライブラリだけ。依存ゼロ（Node 18 以上）
- 外部に何も送りません。ネットワークを使いません（コードに通信用のモジュールを使っていないことを、テストで静的に調べています。実行時の通信を監視しているわけではありません）

## 使い方

```
draftgate draft.md                   # 点検する
draftgate a.md b.txt                 # 複数ファイル
cat draft.md | draftgate -           # 標準入力
draftgate --json draft.md            # JSONで出す
draftgate --config rules.json a.md   # 検出語を追加
draftgate --include-code a.md        # コードブロックの中も点検
draftgate --fail-unverified a.md     # 「未確認」の注記が残っていても失敗にする
draftgate --disable dummy-url a.md   # ルールを無効化
draftgate --help
```

終了コード: 検出あり `1` / なし `0` / 使い方・読み込みの誤り `2`。公開前のフックやCIに入れられます。
インストールせずに試すときは `node bin/draftgate.js draft.md` でも動きます。

## 例

入力（`draft.md`、架空の文章）:

```
## 料金
【要確認】月額は○○円です。
以下に記事を示します。
```

出力:

```
draft.md:2  未解決マーカー  「【要確認】」
draft.md:2  穴埋め  「○○」
draft.md:3  AI定型の前置き  「以下に記事を示します。」
-- 1 ファイル、検出 3 件。内訳: 未解決マーカー 1、穴埋め 1、AI定型の前置き 1（誤検出があります。最終判断は人が行ってください）
```

## 何を拾うか

| ルール名 | 例 |
|---|---|
| `unresolved-marker` | 【要確認】【確認待ち】【運営者確認：…】、【公開しない…】、[要確認] |
| `todo` | TODO、TBD、FIXME、XXX（英数字に挟まれたものは除く） |
| `placeholder` | ○○、□□、「ここに事例を入れる」、[ここに…]、`{{name}}`、lorem ipsum |
| `ai-preamble` | 行頭の「承知しました」「以下のとおりです」「以下が下書きです」「以下に〜を示します」、As an AI、Here is… |
| `duplicate-line` | 8文字以上の同じ行が2回以上（表や区切り線は除く） |
| `unclosed-fence` | 閉じていない ``` / ~~~ |
| `dummy-url` | example.com / .org / .net、localhost、yourdomain.* |
| `unverified` | 「未確認」の件数。**既定では終了コードに影響しません**（`--fail-unverified` で失敗扱い） |
| `custom` | `--config` で足した語 |

## 設定ファイル（`--config`）

```json
{
  "markers": ["社内ペンディング"],
  "patterns": [{ "name": "date", "regex": "20XX年" }],
  "disable": ["dummy-url"],
  "includeCode": false
}
```

`markers` は文字列そのまま、`patterns` は JavaScript の正規表現です。本体に特定の組織名は入っていません。

## 誤検出を減らす工夫

- コードブロック（``` と ~~~）の中は、既定で見ません（`--include-code` で見る）
- インラインコード（`` `TODO` ``）、HTMLコメント、先頭の front matter は見ません
- 行に `draftgate: ignore` と書くと、その行は見ません
- 前置きの検出は行頭だけです。文中の「以下のとおり」は拾いません

## 限界（先に読んでください）

- **誤検出があります。** 会話文の「承知しました、と返した」も拾います。この記事のように、残骸の例を説明するために `example.com` や `TODO` を書いた文章も拾います
- **見逃しもあります。** 辞書と正規表現だけなので、言い換えた前置きや、自分で決めた独自の印は `--config` で足さない限り見ません。字下げ（4スペース）のコードブロックは見分けられません
- 重複行は完全一致だけを見ます。言い回しの近い文は見ません
- 「検出なし」は、公開してよいという意味ではありません。内容の正しさ、法令への適合、機密や個人情報が含まれないことは**確認していません**。最終判断は人が行ってください
- 日本語と英語の一部の言い回ししか対象にしていません。網羅性は未検証です

## プライバシー

読んだ文章は外部に送りません。ネットワークを使いません。ログも保存しません。
