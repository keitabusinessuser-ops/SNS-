# ブランド名「ひとりとAI」等の商標・先使用に関する事前確認
> AIの出力は法的助言ではない。結論は断定しない。専門家（弁理士・弁護士）の確認が必要。
確認日: 2026-10-12 ／ 確認度: **二次情報**（特許庁・J-PlatPatに到達できず。`laws/trademark.md` 参照）。J-PlatPatで「ひとりとAI」を実際に検索してはいない（コンテナから到達不可。Keitaの手元ブラウザでの確認が必要）

## 現状（社内記録より）
- 「ひとりとAI｜AI副業の実験記録」を仮決定（decisions.md 2026-10-11）。「商標・各サービスの空きは未確認」と記録済み。
- Keitaは通常の検索で同名が少ないことを確認。ただしこれは商標の確認ではない。

## 論点
| 論点 | 内容 | 状態 |
|---|---|---|
| 同一・類似の登録商標 | 他人の登録商標と同一・類似で、指定商品・役務も同一・類似だと、使用が侵害の論点になりうる | 未確認（J-PlatPat未検索） |
| 出願中の商標 | 先に出願した者が優先される（先願主義）。出願中でも後で登録される可能性 | 未確認 |
| 未登録でも周知な名称 | 不正競争防止法2条1項1号（周知表示の混同）の論点。J-PlatPatには出ない | 未確認（通常のWeb検索・SNS検索で補う） |
| 先使用 | 自分が先に使っていても、先使用権は要件が厳しい。当社は公開直後で、周知性は期待できない | 専門家確認 |
| 一般的な語の組み合わせ | 「ひとり」「AI」は一般的語で、識別力・独占性は弱い可能性（出願しても拒絶のおそれ、他人も使いやすい） | 専門家確認 |

## J-PlatPatでの検索手順案（Keita本人 or 画面に到達できる環境で。仮説）
| ステップ | 内容 |
|---|---|
| 1 | J-PlatPat（特許情報プラットフォーム）の「商標」検索を開く。検索対象は登録・出願中の両方 |
| 2 | 称呼（読み）検索: 「ヒトリトエーアイ」「ヒトリトエイアイ」「ヒトリトAI」等、表記ゆれを並べる。部分一致（前方一致・中間一致）も試す |
| 3 | 文字商標の検索: 「ひとりとAI」「ひとりとAi」「ヒトリトAI」「ひとりとエーアイ」 |
| 4 | 分類で絞る: 国際分類の第9類（ソフトウェア）、第35類（広告・事業支援）、第41類（出版・電子出版物の提供・教育・セミナー）、第42類（ウェブサイト・ソフトウェア提供）、第16類（印刷物）が候補（記憶ベース・未確認）。類似群コードも確認 |
| 5 | 該当が出たら、権利者・指定商品役務・状態（登録/出願/拒絶等）をメモ（個人名が出る場合は記録に残さない） |
| 6 | Web・SNS・アプリストア・GitHub・note・X・YouTubeで同名・類似名の使用例を検索（未登録の先行使用の確認） |
| 7 | 結果を `brand-name` のメモとして残し、少しでも類似があれば弁理士に相談 |

## 名前を使う場面ごとの確認
| 名前の使い道 | 確認すること | 備考 |
|---|---|---|
| サイト名・note表示名・SNSアカウント | 上記1〜6 | 現在使用中または使用予定 |
| GitHub組織名・URL（hitori-to-ai） | 組織名の空き＋商標の確認 | 空き＝権利クリアではない |
| 将来の組織名（会社・屋号） | 法人化・開業時に再検索 | 事業開始時の屋号は商標とは別だが、名称の使用は商標の論点 |
| 連載名（やらかし事業部 など） | 同様に確認 | 一般語に近い場合は識別力が弱い |
| 商品名（型・テンプレ・ツール） | 売る前に確認。区分は第9類・第41類・第42類等 | 費用が出る出願は承認ゲート3 |
| ロゴ | 図形の類似も調べる | 他社ロゴに似せない |
| 「AI」を含む名称 | 同様の語を含む名称が多い。単語単位でなく全体の類似を検討 | 文字の組合せでの判断（解説） |

## 専門家確認が必要な点
- J-PlatPat検索結果の評価（類似か）、使用の可否、出願するか・どの区分か
- 先使用・周知性の主張可否、将来の組織名での再確認、警告書受領時
