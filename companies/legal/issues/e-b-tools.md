# 小ツール・用語集ページ（E-B）公開時の注意（他サイト文章・辞書の転載、出典、免責、誤情報）
> AIの出力は法的助言ではない。結論は断定しない。専門家（弁護士）の確認が必要。
確認日: 2026-10-12 ／ 確認度: **二次情報**（著作権法は `laws/copyright.md` 参照。e-Gov・文化庁に到達できず）。語釈・用語集の著作物性を直接扱った裁判例は検索で見つからなかった

## 対象
GitHub Pages上の小ツール（文字数カウント、和暦西暦、日数計算、トークン概算）とAI用語集（`site/e-b-topics-01.md`）。

## 論点（表）
| 論点 | 問われうる点 | 注意・対応案（仮説） | 確認度 |
|---|---|---|---|
| 他サイト・辞書の文章の転載 | 語釈・解説文を写すと、複製・翻案の論点（創作的な表現なら）。短い定義でも、言い回しが酷似すると問題になりうる | 他の辞書・用語集・記事の文を貼らない。AI用語集は自分の言葉で書き、元資料を丸写しした文をAIに書き換えさせて出さない | 二次情報 |
| AIで書いた用語説明 | 既存文章に酷似する可能性（依拠性・類似性）。生成物の著作物性も不確実 | 公開前に主要な既存説明と見比べる（酷似チェック）。定義は独自の構成・例を付ける | 二次情報 |
| 用語の事実・定義自体 | 事実・アイデアは保護対象外とされる一方、表現は別 | 事実は一次情報で確認し、表現は独自に | 二次情報 |
| データの転載（祝日表、換算表等） | データベースの著作物・権利者の利用条件。公的データも利用規約あり | 祝日・時給換算は誤情報リスクもあり第1弾では避ける（decisions.md 2026-10-12）。使うなら出典の利用条件を確認 | 一部未確認 |
| 引用する場合 | 自分の文が主、引用部分を明確に区別、出典明示、必要最小限、改変しない（32条の要件の理解。48条の出所明示） | 用語集では原則引用せず、リンクで出典を示す | 二次情報 |
| 出典の表示 | 参照した一次情報（公式文書・仕様）の名称・URL・確認日を書く | 各ページ末尾に「参考」「確認日」を置く。複数ページで同じ書式 | — |
| 免責 | 「結果の正確性は保証しない」の記載は有益だが、故意・重過失や消費者契約法上の無効のおそれ（消契法の論点。未蓄積）があり、免責文だけで責任が消えるとは限らない | 免責は入れるが、「正確さを保つ努力」（出典・更新日・誤り報告窓口）とセットにする。専門家確認 | 一部未確認 |
| 誤情報 | 計算ツールの誤り、古い情報（法令・料金・仕様）で利用者が損害を受けた場合の責任の論点 | 計算ロジックのテスト、境界値の確認、更新日の表示、「重要な判断は公式情報で」の注記。法律・税務・医療・金融の計算は避ける（専門家領域） | 一般論 |
| 専門領域 | 法律・税務・医療・金融に踏み込む説明は、専門家領域の助言と受け取られうる | 一般的な情報提供に留め、個別事情の判断はしない旨を明記（`CLAUDE.md` の方針） | — |
| 他社名・サービス名・商標 | AI関連の用語集で他社サービス名・商品名を扱う | 事実に基づく言及に留める。ロゴは使わない。他社の評価を断定しない（景表法・名誉の論点） | `trademark.md` |
| 画像・フォント・ライブラリ | 素材・OSSのライセンス表記 | 使う素材のライセンスを確認し、必要なクレジットを表示 | 未確認 |
| アクセス解析・外部送信 | ツールにアクセス解析を入れる場合の通知・公表 | `issues/site-analytics.md` | — |
| 広告・アフィリエイト | リンクを載せるなら、表示・ステマ規制 | 現時点では載せない方針。載せる前に `stealth-marketing.md` 等を確認 | — |
| 入力データの扱い | ツールに利用者が入力するテキストの扱い。サーバーに送らず端末内で完結させる設計なら論点は小さい（設計次第） | 入力を外部に送らない設計にし、ページに明記。送る場合は個人情報保護法・外部送信の論点 | `appi.md` |
