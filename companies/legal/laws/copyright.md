## 要点（二次情報）
| 論点 | 要点 | 備考 |
|---|---|---|
| 著作物性（2条1項1号とされる） | 「思想又は感情を創作的に表現したもの」。事実・データ・アイデア・作風・画風そのものは対象外。ありふれた表現は創作性が否定されうる | 条文は未確認。短い定義文・事実の羅列は著作物性が否定されやすいとの一般論（解説） |
| 複製・翻案・公衆送信 | 無断コピー（複製権）、改変して新たな作品にする（翻案権・27条とされる）、ネット公開（公衆送信権・23条とされる）は権利者の許諾が原則必要 | 条番号は記憶ベース、原文未確認。ブログ・サイトへの転載はこれらに当たりうる |
| 侵害の判断 | 「依拠性」（既存著作物に基づいて作った）と「類似性」（表現上の本質的特徴を直接感得できる）の両方（解説）。偶然の一致は依拠性がなく侵害になりにくいとされる | 文化庁整理の解説経由 |
| 引用（32条1項とされる） | 公表された著作物を、①引用して利用し、②公正な慣行に合致し、③報道・批評・研究などの引用目的上正当な範囲内で行う場合は許諾不要（検索結果の要約） | 最高裁昭和55年パロディ・モンタージュ事件の「明瞭区分性」「主従関係」が基準として語られる。近年は総合判断の裁判例もある（解説）。要件を1つでも外すと侵害のおそれ |
| 出所明示（48条とされる） | 出所の明示は別条。32条の要件そのものでないとする見解がある一方、「公正な慣行」の判断で考慮された例がある。知財高裁平成30年「沖縄 うりずんの雨」事件で、出所不明示が公正な慣行に合致しないとされた例（解説） | 実務では出典を明記し、改変しない |
| 生成AIの学習（30条の4とされる） | 思想又は感情の「享受」を目的としない利用は許諾不要。ただし著作権者の利益を不当に害する場合は除く（解説） | 文化庁は令和6年3月に「AIと著作権に関する考え方について」を公表（法制度小委員会。複数の解説で確認）。学習段階と生成・利用段階を分けて整理 |
| 生成・利用段階 | 30条の4は「生成物を公開・販売する場面」には及ばず、既存著作物と類似性・依拠性があれば侵害になりうる（解説）。固有名詞や既存作品を入力した場合などは依拠性が認められやすい（解説）。利用者が認識していなくても、学習データに含まれていれば依拠性が認められうるとの整理（解説） | 文化庁「AIと著作権に関するチェックリスト＆ガイダンス」（令和6年7月）も公表とされる（本文未確認） |
| AI生成物の著作物性 | AIが自律的に生成したものは、人間の創作的寄与がなければ著作物と認められにくい（解説）。人間の指示・選択・加筆の程度で変わりうる | 具体的な線引きは個別判断。公式文書は未確認 |
| データベース | 情報の選択・体系的構成に創作性があれば著作物（12条の2とされる）。創作性を否定した裁判例も多い（解説） | 条文・個別判決は未確認 |

## 当社の事業との関係
| 場面 | 論点 | 対応案（仮説。専門家確認が必要） |
|---|---|---|
| サイト・note記事での他者の文章の使用 | 無断転載は複製・公衆送信の論点。引用は要件（自分の文章が主、引用部分を明確に区別、出典明示、必要最小限、改変しない）を満たす設計に | 原則「要約して自分の言葉で書く＋出典リンク」。長文の引用はしない。出典を必ず付ける |
| 口コミ・他人のSNS投稿・レビュー | 投稿も著作物になりうる（短文・事実のみなら創作性が否定される場合もあるが、一律ではない）。投稿者の人格・プライバシー、プラットフォーム規約も別論点 | 本文の転載・デモ使用はしない（CLAUDE.mdの礼節ルールとも整合）。数値や事実の抽象化に留める |
| AIで作った文章・画像の公開 | 既存作品に酷似しないか（類似性・依拠性）。生成物に自分の著作権が認められるかは不確実 | 特定作家・作品名・キャラクターを指定した生成は避ける。画風指定も避ける。AI利用の開示方針は別途（`research/04-legal.md`） |
| 小ツール・用語集（E-B） | 他サイトの辞書・用語集の転載は複製・翻案の論点 | `issues/e-b-tools.md` 参照 |
| 画像・フォント・アイコン・スクショ | 素材のライセンス条件（商用可・クレジット表示）。他社サイトのスクリーンショットは引用の要件を要確認 | ライセンスを確認した素材のみ。出所メモを残す |
| オープンソース・ライブラリ | コードのライセンス（MIT等）の条件遵守 | 個別に確認（本ファイルでは未調査） |
| AIサービスへの他人の著作物の入力 | 30条の4は学習段階の整理。入力先の規約（学習利用の有無）も別途 | 他者の記事を丸ごと入力して要約・リライトさせ、そのまま公開することは避ける |

## よくある落とし穴
- 「出典を書けば何でも引用できる」と考える（要件は出典明示だけではない。主従関係・必要性など）
- 「AIが作ったから自分の著作物／誰の権利も侵害しない」と考える（どちらも保証されない）
- 「30条の4があるからAI生成物の公開も自由」と考える（学習段階と利用段階は別）
- 要約・言い換えでも、表現や構成が元記事に近いと翻案の論点になりうる
- 写真やイラストを「ネットで拾った」ものとして使う

## 専門家確認が必要な点
- 引用の可否（具体の使い方）、AI生成物の著作物性・権利帰属の扱い、AI生成物を販売・有料公開する場合
- 他者の文章・データを素材にした商品（ツール・データ集）の設計
- 他者からの権利侵害の申立てがあった場合の対応
