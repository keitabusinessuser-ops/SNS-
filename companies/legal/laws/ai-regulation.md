# AI関連（AI事業者ガイドライン・AI推進法・生成AIの利用規約・AI生成物の開示）
> AIの出力は法的助言ではない。結論は断定しない。専門家（弁護士）の確認が必要。著作権の論点は `laws/copyright.md` に譲り、ここでは重複を避ける。

|---|---|

| 所管 | AI推進法は内閣府（AI戦略本部）、ガイドラインは総務省・経産省 |
| 確認日 | 2026-10-13 |
| 確認度 | 政府側は**二次情報**（soumu.go.jp・cao.go.jp・e-Govに到達できず。getaddrinfo失敗を実測。検索結果の要約のみ）。Anthropicの規約は anthropic.com の公式ページを取得できたが、**小モデルによる要約経由**で逐語は未読（一次寄りの二次） |

## 3. 生成AIの利用規約（Claude等）に関する留意点
| 論点 | 要点（Anthropic Consumer Terms、公式ページの要約） | 確認度・注意 |
|---|---|---|
| 年齢 | 18歳以上、または居住地で同意に必要な年齢のいずれか高い方 | 公式（要約経由）。Keitaの年齢が**未確認**。成年でない場合は利用自体の論点（`issues/contracts-minors.md`） |
| 適用規約 | Claude.ai・Claude Pro の個人利用は Consumer Terms。APIキー・Console等は Commercial Terms | 公式（要約経由）。どの経路で使うかで規約が違う |
| 出力の権利 | 入力の権利は利用者に残る。出力はAnthropicが持つ権利（あれば）を、規約遵守を条件に利用者に割り当てる、との趣旨。**出力の正確性は保証されず、利用前に独立して確認すべき** | 公式（要約経由）。著作権が成立するか、第三者権利を侵害しないかは別問題（`laws/copyright.md`） |
| 学習への利用 | アカウント設定でオプトアウト可。ただしフィードバックや安全性レビューの対象は学習に使われうる。**入力に個人情報・機密・店舗情報を入れない**（憲章の漏洩ゲートと直結） | 公式（要約経由）＋二次（2025年8月の改定報道） |
| 禁止事項 | 法令違反、競合製品開発、再販、無許可のスクレイピング、API以外での自動化、知的財産権侵害など | 公式（要約経由） |
| 利用ポリシー（AUP） | スパム、なりすまし・架空ペルソナ、ステマ・サクラレビュー、人間を装うボット等を禁止。**発効日が「2026年11月12日」と表示（本日より先。要約の誤りか未来の版かは未確認）** | 公式（要約経由）。**再確認が必要** |
| 他社AI | OpenAI、Google等の規約は**未調査** | 未確認 |

## 4. AI生成物の開示
| 論点 | 要点 | 確認度 |
|---|---|---|
| 一般の法的な表示義務 | 今回の調査では、**日本でAI生成コンテンツ全般に一律のラベル表示義務を課す法令は確認できなかった**（景表法・総務省資料を狙った検索でも該当なし。「無い」と断定はできない） | 未確認 |
| Anthropic AUP | 一般的なAI生成コンテンツのラベル表示義務は明記なし。一般ユーザーと直接対話するチャットボットは、AIと対話していることの開示が必要。高リスク分野でのAI関与は影響を受ける本人に開示 | 公式（要約経由） |
| 自主ルール | JDLA「生成AIの利用ガイドライン（画像編）」は、生成プロセスの明示を推奨的に扱う。Adobe Stockは投稿時のAI生成の明示が必要。**プラットフォームごとに違う** | 二次 |
| 広告・ステマ | AIが書いた体験談・口コミを実体験のように見せる、実在しない人物の推薦文などは、景表法（優良誤認・ステマ）や AUP（サクラレビュー）の論点になりうる（`laws/keihyoho.md`、`laws/stealth-marketing.md`） | 仮説 |
| 当社の運用 | サイトの方針は「AIで運営していることを隠さない」。**開示は法的義務というより、信頼とプラットフォーム規約の問題**として運用し、記事にAI関与を明記する。実在人物に見せかけない | 仮説。専門家確認が必要 |

## 当社の事業との関係
| 場面 | 論点 |
|---|---|
| 記事・画像・ツールのAI生成 | 規約の出力権利、正確性の独立確認、著作権・商標・肖像の確認（優先3の各ファイル）、AI関与の開示 |
| AIへのデータ入力 | 個人情報・取引先情報の入力は漏洩ゲート。学習利用の設定の確認 |
| 小ツールを他人に提供 | AI提供者の区分、ガイドライン、チャットボット型ならAIである旨の開示 |
| 営業・連絡の自動化 | スパム禁止（AUP）、`laws/tokutei-email.md` |
| AIによる運営の発信（ブランド） | 「AIが書いた」ことと「Keitaが確認した」ことの分離表示。実績の誇張を避ける（景表法） |

## よくある落とし穴
- AIの出力をそのまま「自分の経験」として書く（虚偽・優良誤認・信頼毀損）
- 「出力の権利が割り当てられる」を「第三者の権利侵害がない」と読む
- ガイドラインを「法的義務」または「無関係」と極端に読む（ソフトロー。ただし取引先・規約・裁判で参照されうる）
- 古い規約・版数を引用する（規約は頻繁に改定される）

## 専門家確認が必要な点
- AI推進法・ガイドラインの当社への適用（努力義務の範囲）
- AI生成物の開示方法、ステマ・景表法との関係
- 規約（Claude等）の商用利用・再販・自動化の範囲、規約同意と年齢（Keitaが成年でない場合）
