## 1. 所得区分（事業所得・雑所得）
| 論点 | 要点（二次情報） | 注意 |
|---|---|---|
| 区分 | アフィリエイト等のネット収入は、継続的・安定的で事業性があれば事業所得、そうでなければ雑所得、と整理されることが多い。国税庁No.1300を引用した記事では、アフィリエイトは雑所得だが事業所得にも認定されうる類型とされる | 「副業＝雑所得」とは限らない。判断は個別。**税務署・税理士に確認** |
| 300万円の目安 | 副業の区分で「前々年の収入300万円」と帳簿書類の保存が関わる、という趣旨の解説を確認（2022年の通達改正の話と思われるが、通達番号・要件の細部は**未確認**） | 申告の要否の基準ではなく区分の判定の話、と解説されている。原文は未読 |
| 開業届・青色申告 | 事業所得なら開業届・青色申告承認申請書などの論点（青色の特別控除等）。雑所得では青色申告の特別控除は使えない、という整理が一般的（**未確認**） | 当面の収益がほぼゼロの想定でも、届出の要否は税務署に確認 |
| 損益通算 | 雑所得の赤字は他の所得と通算できない、という整理が一般的（**未確認**） | 経費（サーバ代、AI利用料等）の扱いと併せて確認 |

## 2. 副業収入の申告が要る目安
| 論点 | 要点（二次情報） | 確認度・注意 |
|---|---|---|
| 20万円ルール | 給与所得者（会社員等）で、給与以外の所得（収入−必要経費）が年間20万円以下なら、所得税の確定申告は原則不要。**収入ではなく所得**で判定 | 二次情報。「給与の年間収入が2,000万円以下」などの前提条件あり（一般知識、今回未確認） |
| 住民税は別 | 20万円以下でも、住民税の申告は別途必要、と複数の解説。申告時期は例年2/16〜3/15（住民税は市区町村の窓口） | 二次情報。**市区町村に確認** |
| 例外 | 控除を受ける・源泉徴収税の還付を受ける場合は、20万円以下でも確定申告が必要になりうる | 二次情報 |
| 給与がない人 | 給与所得者でない場合（給与収入がない学生等）は、所得が基礎控除額を超えるかなど別の判定になるはず（**未確認**） | **学生のKeita本人に当てはまるかは、税務署に確認** |
| ASPからの報酬 | 報酬が所得に当たるか、源泉徴収・支払調書の扱いはASPごと。**未確認** | ASPに確認 |

## 3. 学生の収入の壁（2025〜2026年の改正の有無）
改正は**あった**（二次情報）。数字の細部は解説記事間で揺れがありうるため、**国税庁・自治体・健保組合の一次情報で再確認が必要**。

| 区分 | 壁（二次情報） | 改正の有無・メモ |
|---|---|---|
| 本人の所得税がかかり始める目安 | 令和7年分から、給与収入ベースで**160万円**（基礎控除95万＋給与所得控除最低65万）と解説 | 改正あり（令和7年度税制改正）。国会審議で基礎控除の特例が追加され、大綱の数値と一部異なる、との注記あり |
| 令和8年度税制改正 | 基礎控除の本則が58万→62万、「年収の壁」が**178万円**（2年間の限定措置）と解説。令和8年分の年末調整から適用 | 二次情報（税理士・会計系）。**160万円との関係・適用年分は未確認**。学生バイトに直結する扶養関係は今回確認できず |
| 住民税（本人）の非課税の壁 | 100万円→**110万円**（令和7年の収入を基礎とする令和8年度住民税から）と解説 | 改正あり（二次）。自治体により級地・加算が異なる可能性（未確認） |
| 親の扶養控除・配偶者控除の壁（子の給与収入） | 103万円→**123万円**（子の合計所得58万円）と解説 | 改正あり（二次） |
| 特定親族特別控除（19〜22歳の子等） | 新設。親側は、子の年収**150万円**までは満額（63万円）、188万円に向けて段階的に減少と解説 | 改正あり（二次）。子本人の所得税・住民税が減るのではなく、**親の税額に影響**。親の勤務先の扶養手当の基準は別（会社の規程） |
| 勤労学生控除 | 合計所得の上限が75万→**85万円**（給与収入150万円相当）。勤労所得以外の所得が10万円以下であること。所得税27万円・住民税26万円。住民税は令和8年度分から | 改正あり（二次）。所得税では基礎控除引上げでメリットが薄れた、との解説あり。**事業所得・雑所得（アフィリエイト）が「勤労による所得」に当たるか、10万円以下の枠の扱いは未確認。税務署に確認** |
| 健康保険の被扶養者（親の扶養） | 原則130万円未満。**19歳以上23歳未満（配偶者除く）は2025年10月1日から150万円未満**（社会保険研究所・社労士系の解説。厚労省最終通知本文は未読） | 改正あり（二次）。2026年4月1日から、給与収入のみの場合は労働契約の賃金から見込む年収で判定する運用に、との解説（**未確認**）。**副業の雑所得・事業所得が「年間収入」にどう算入されるかは未確認。健保組合に確認** |
| 社会保険の加入（106万円の壁） | 賃金要件（月8.8万円）の撤廃が2026年10月施行予定と解説（日付は記事間で差の可能性。**未確認**）。週20時間要件等は残る。学生は適用除外の扱いがある（一般知識、**今回未確認**） | 改正あり（2025年6月成立の年金制度改正法、二次）。アフィリエイト等の自営収入は被用者保険の加入要件とは別論点 |
| 国民年金・国保 | 学生納付特例など。今回**未調査** | 20歳以上なら国民年金の論点。年齢未確認 |

## 4. インボイス制度・消費税（免税事業者の基礎）
| 論点 | 要点（二次情報） | 注意 |
|---|---|---|
| 免税事業者 | 基準期間（原則、前々年）の課税売上高が1,000万円以下で、適格請求書発行事業者でない事業者は、消費税の納税義務が免除、と解説（特定期間などの例外は**未確認**） | 学生・個人も事業者として売上があれば同じ枠組みのはず（**未確認**） |
| 登録は任意 | 適格請求書発行事業者の登録は事業者本人の判断。登録しないと取引先が仕入税額控除を使えず、値下げ要請等の影響がありうる、との解説 | 取引先がASP・企業の場合の影響は**ASPごとに未確認** |
| 登録すると | 課税事業者になり、消費税の申告・納税が必要。氏名・住所等が公表事項になりうる（一般知識、**今回未確認**） | **ペンネーム運営との整合・個人情報（住所）の公表の論点。税務署・税理士に確認**。漏洩ゲート（個人情報）にも該当 |
| 2割特例 | 小規模事業者の負担軽減。適用期間は**2026年9月30日を含む課税期間まで**（個人は2026年分まで）。**2027年以降は使えない**と複数解説 | 二次。本日（2026-10-13）時点では**すでに終了した特例**。新規登録を考える場合は使えない前提で |
| 3割特例 | 2026年度税制改正で、**個人事業者のみ**2027年・2028年に納付税額を売上税額の3割とする特例が新設、と1つの解説（税理士系） | **単一の二次情報。要一次確認（国税庁）。** 適用要件は未確認 |
| アフィリエイト報酬 | 課税売上に当たるか、免税点以下かの判定は取引の内容次第。ASPからの報酬の消費税区分は**断定できない** | 売上が出る前に税務署・税理士へ |

## よくある落とし穴
- 「20万円」は**所得**基準で、**住民税は別**。申告不要と思い込む
- 「103万円・130万円」など古い壁の数字のまま判断する（2025〜26年に改正あり）
- 所得税の壁、住民税の壁、親の扶養控除の壁、健保の被扶養者の壁、会社の扶養手当の壁は**別々**
- 雑所得の年間収入が健保の被扶養者認定にどう影響するかを確認せず、親の扶養を外れる
- 免税事業者なのに請求書・領収書へ消費税を別建て表示する、登録番号を使わず適格請求書と誤認させる（一般的な論点。**未確認**）

## 専門家確認が必要な点（税理士・税務署）
- 本人の所得区分、申告要否、住民税の申告、開業届・青色申告の要否
- 学生としての各種控除（勤労学生控除）と、親の特定親族特別控除・扶養への影響、親の勤務先の手当
- 健保の被扶養者認定と副業収入の扱い（健保組合）、国民年金・国保
- 消費税の課税事業者判定、インボイス登録の要否・ペンネームとの関係、3割特例
- 税務の相談は、税理士でない者が有料で行うことに制限がある（税理士法。一般知識、**未確認**）ため、当社は一般情報の整理にとどめる
