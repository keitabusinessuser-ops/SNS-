## 要点（二次情報）
| 論点 | 要点 | 確認度・注意 |
|---|---|---|
| 契約の成立 | 申込みと承諾の意思表示の合致で成立（民法522条。**一般知識、今回の検索では確認せず**）。書面は原則不要（口頭・メール・ネットでも成立しうる）。電子的な承諾通知は、承諾が到達した時に成立する、との解説（METI 2011年資料。2017年の民法改正後の条文番号は未確認） | 一般知識の部分は未確認と明記 |
| 電子消費者契約法 | 消費者と事業者のネット契約で、事業者が画面で手続を示す契約が対象（消費者同士のフリマ・オークションは対象外）。確認画面など申込み意思を確認する措置がない場合、消費者の操作ミス（錯誤）の主張が通りやすくなる、という趣旨の特例（解説） | 条文は未読 |
| 未成年者の法律行為（民法5条） | 未成年者が契約するには法定代理人（親権者等）の同意が必要。同意なしの契約は取り消せる。例外: 法定代理人が処分を許した財産（目的を定めたもの、定めないもの＝お小遣い）の範囲内、単に権利を得る・義務を免れる行為（5条1項ただし書は一般知識）。取消しは本人・法定代理人のどちらからも可（自治体資料） | 例外の細部は未確認 |
| 成年年齢 | 民法4条で18歳。**2022年4月1日**施行。18歳・19歳は未成年者取消権を使えない（自治体・法務省Q&A解説）。結婚による成年擬制は削除（一般知識。未確認） | 飲酒・喫煙・公営競技などは20歳のまま（一般知識。未確認） |
| 詐術（民法21条） | 未成年者が成年と偽る等、相手を誤信させる詐術を用いた場合は取消しできない。ただし「成年ですか」にクリックで「はい」と答えさせただけのネット通販では詐術に当たらないと考えられている、との解説。事業者の誘導や画面構成を含む個別判断 | 判例は未確認 |
| 取消しの効果 | 取消し後は原則として現存利益の返還（121条の2。一般知識、未確認） | 未確認 |
| 定型約款（民法548条の2〜548条の4） | 定型取引（不特定多数相手で内容が画一的であることが合理的な取引）の合意をした者は、①定型約款を契約内容とする合意をしたとき、②あらかじめ定型約款を契約内容とする旨を相手に表示していたとき、個別条項にも合意したとみなされる（548条の2第1項）。相手方の権利を制限し義務を加重して信義則に反し一方的に害する条項は、合意しなかったものとみなされる（同2項）。548条の3: 取引前後の相当期間内に請求があれば遅滞なく相当な方法で内容を示す義務（事前に提供していれば例外）。548条の4: 相手の一般の利益に適合する場合、または契約目的に反せず変更の必要性・内容の相当性等から合理的な場合は、個別同意なしに変更でき、効力発生時期を定め、周知が必要 | 解説サイトの要約。条文原文は未読 |
| 利用規約への同意が有効になる条件 | 検索では日本の判例は確認できず（米国の事例の解説のみ）。一般的な整理としては、規約を契約内容とする旨の表示、相手が内容を確認できる状態（容易にアクセスできるリンク等）、同意の操作（チェック・ボタン）、同意の記録保存が論点（**一般論。未確認**）。サイト下部のリンクのみで足りるかは「相当な方法」の個別判断で、日本の裁判例は今回確認できず | **未確認の点が大きい** |

## 当社の事業との関係
| 場面 | 論点 | 対応案（仮説。専門家確認が必要） |
|---|---|---|
| 将来の有料商品・C社の受注 | 契約の成立時点、規約の組み込み、変更手続。契約書・規約・特商法表記が整うまで課金・受注しない（憲章） | 規約は専門家確認後。表示・同意方法を設計 |
| 利用者に学生・未成年がいる可能性 | 親権者の同意がない契約は取り消されうる | 有料商品は18歳以上限定と明記＋年齢確認の限界を理解（詐術に当たらない可能性がある点に注意）。`issues/contracts-minors.md` |
| 運営者自身が契約の当事者になる（ASP・決済・SaaS） | 運営者の年齢次第で、取消権・親権者同意の論点が自分に生じる。規約の年齢条件に違反すると利用停止等 | `issues/contracts-minors.md` |
| 規約の変更 | 548条の4の要件（周知・合理性）。無断の不利益変更は避ける | 変更履歴・周知を残す |

## よくある落とし穴
- 「同意ボタンを押させたから有効」と考える（表示・内容・不当条項の問題が残る）
- 「18歳以上と自己申告させたから安心」と考える（詐術に当たらない可能性。個別判断）
- 「18歳は成年になったから親の同意は不要」と考える際に、規約や決済会社側の年齢条件（別基準の可能性）を見落とす
- 一方的に有利な条項（免責の全面的な否定など）は不当条項として効力を否定されうる（消費者契約法とも重なる。`消費者契約法` は未蓄積）
