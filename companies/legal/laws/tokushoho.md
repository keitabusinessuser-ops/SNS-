## 通信販売の要点（二次情報。条番号は要約ベース）
| 論点 | 要点 | 備考 |
|---|---|---|
| 広告の表示事項（11条） | 販売価格、送料等、代金の支払時期・方法、引渡時期、返品（申込み撤回・解除）に関する事項、販売業者の氏名（名称）・住所・電話番号など | 通販にはクーリング・オフは無い。返品特約の表示が重要（15条の3、要約。未確認） |
| 「請求があれば開示」方式 | 11条1項ただし書・施行規則10条。広告に「請求があれば遅滞なく開示」と書くなど条件を満たせば、一部事項の表示を省略できる（markezine要約）。氏名・住所・電話番号は規則上省略可能とされるが、**開示の運用が条件**（issoh要約）。代金の支払時期は、前払いの場合は全部表示しないと省略できないと解説 | 省略範囲は要約間で食い違いあり。**確定できない**（04-legal.md と同じ） |
| 誇大広告等の禁止（12条） | 著しく事実と違う、実際より著しく優良・有利と誤認させる表示の禁止（要約。条番号は未確認） | 景表法と重なる |
| 申込み段階の表示（12条の6） | 2022年6月1日施行。最終確認画面で、分量・価格・支払時期/方法・引渡時期・申込期限・撤回解除条件を表示。誤認させる表示は禁止（impress要約） | 有料の型のチェックアウト画面で効く |
| 撤回妨害の不実告知（13条の2） | 申込み撤回・解除に関し不実を告げる行為の禁止（要約） | |
| 行政処分 | 指示・業務停止等（条番号未確認） | |

## 「販売業者」に当たるか（個人・学生）
- 解説では、「営利の意思」と「反復継続性」を客観的に総合して判断する、とされる（二次情報。https://markezine.jp/article/detail/291 ほか）
- 個人であることだけでは免れない可能性がある。副業・継続販売は該当の可能性がある。学生であることの特別扱いは、**確認できていない**
- 氏名・住所の開示を巡る実務（ペンネーム、バーチャルオフィス、住所非公開）の可否は**未確認**。プラットフォーム（note等）の表記機能と非公開範囲も未確認

出典（二次）: https://markezine.jp/article/detail/292 ／ https://www.issoh.co.jp/column/details/18188/ ／ https://netshop.impress.co.jp/node/9750 ／ https://sogyotecho.jp/tokuteishoutorihikihou-ec/
一次情報の所在: 消費者庁 特定商取引法ガイド https://www.no-trouble.caa.go.jp/what/mailorder/advertising.html ／ e-Gov

## 当社の事業との関係
| 場面 | 論点 | 対応案（仮説。専門家確認が必要） |
|---|---|---|
| 無料の公開サイト（広告なし） | 販売をしていない段階では通販の表示義務は主要な論点にならない可能性（断定不可） | 無料記事は先行可（04-legal.md の方針） |
| 将来の有料の型（デジタルコンテンツ）の販売 | 通信販売として11条・12条の6の対象になりうる。デジタルコンテンツの位置づけ（商品／役務／権利）や返品特約の扱いは**未確認** | 表記が整い、専門家確認が済むまで課金しない（CLAUDE.md） |
| 販売者情報の表示 | 氏名・住所・電話番号を出すか、「請求があれば開示」方式にするか。個人情報・漏洩ゲートにも関わる | 窓口（弁護士/消費生活センター）に、①販売業者に当たるか ②開示方式でよいか ③開示請求時の手順、を確認 |
| プラットフォーム経由（note等） | プラットフォームの特商法表記機能で足りるか、運営者個人の責任は別に残るか | 規約原文を確認（未確認） |
| アフィリエイト（紹介のみ） | 紹介者自身が販売業者でない場合は11条の対象外の可能性。ただし誇大な勧誘文言は別論点 | 専門家確認が必要（affiliate-notes.md でも未確認としている） |
| 未成年・学生 | 契約の取消し等は民法側の論点（優先5） | 年齢・親権者の同意は別途 |

## 落とし穴
- 「個人だから不要」「noteが代わりに表記してくれる」と思い込む
- 返品不可のつもりでも、表示がないと返品を受ける扱いになりうる（要約。未確認）
- 最終確認画面を作らない、価格以外の条件（期間・回数）が分かりにくい
- 景表法・ステマ規制・消費者契約法（優先1の残り）が併せて問われる
