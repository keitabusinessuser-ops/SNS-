# 問いリスト v0（1問ずつ出す。答えにくければ選択肢にする）

## A 過去の棚卸し（スタンス反映: 弱さの棚卸しを最初に。事実で書く）
0. 自分の弱さを3つ、事実で書くと？（例:「営業経験がない」「継続が3回途切れた」。評価語は使わない）
1. 今までで「時間を忘れて没頭した」経験を1つ。何をしていた？
2. 人から「それ得意だね」「助かった」と言われたことは？（3つまで）
3. 続かなかったこと・やめたことは？ なぜやめた？ （A: 飽きた／B: 結果が出ない／C: 他が忙しい／D: 人間関係／E: その他）
4. 過去の失敗で、一番学びが大きかったのは？（note・事業の失敗含む）
5. 逆に、やっていて消耗したことは？
6. 「丸投げ・全自動化・AI出力の鵜呑み」で失敗した3回、共通する原因は何だと思う？
→ 出力: 強み仮説5つ／失敗パターン

## B 現在地
1. 週に自由に使える時間は？（平日／休日。朝・夜どちらが確保しやすい？）
2. 月に事業へ使えるお金は？（今は0円前提でいい？）
3. 今ある武器: スキル・資格・ツール・人脈（特定できない形で）・発信アカウントの数字
4. 今やっていること（本業・学業・事業）と、それぞれの週あたり時間
5. 生活上の制約（年齢、居住、家族、公開したくないこと）
6. 今の月収と、月50万が実現したら何が変わる？（金額の根拠）
7. 今の自分を10点満点で採点すると？ 理由は？ （収入／スキル／時間／メンタル／環境）
→ 出力: 現在地シート1枚

## C 未来
1. 3年後の平日1日をどう過ごしていたい？（朝起きてから寝るまで）
2. 絶対にやりたくないことは？
3. 月50万の「その先」は？ （なぜ50万？ 100万なら何が違う？）
4. 母親・子育て世帯の支援という将来設計：いつ頃、どんな形で？ 資金はいくら必要？
5. 12ヶ月後に「やってよかった」と言える状態は？（数字1つ＋状態1つ）
6. 6ヶ月後の中間地点は？
→ 出力: 目標文（何を・いくら・いつまでに・なぜ）
