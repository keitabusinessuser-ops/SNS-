# ナレッジベース（成功・失敗・ツール・効率化の蓄積）

目的: 経験を資産にし、他の事業・アカウントに横展開できるようにする。毎週、CEOが振り返り、最新版に更新する。

| ファイル | 内容 |
|---|---|
| `successes.md` | うまくいったこと（条件・数字・再現手順） |
| `failures.md` | うまくいかなかったこと（原因・数字・次に変えること） |
| `tools.md` | ツールの探索と評価（用途・費用・規約・結果・採否） |
| `efficiency.md` | 効率化の工夫（前後の工数、再現手順） |

## 書き方
- 事実と推測を分ける。数字には日付と出典を付ける
- 企業名・個人名・特定できる情報は書かない
- 新しい順。古い情報は消さず、「更新」「無効」を付ける
- 1件の形式: 日付／何をしたか／結果（数字）／原因・学び／次に変えること
