# 公開前の確認（Keita用。3分で終わる形）
目的: 「運営者が確認して公開」を、実態にする。確認のやり方が分からない、という指摘（2026-10-11）への対応。
流れ: ①AIが確認用の画像と要点をDriveの「要確認」に入れる → ②Keitaが下の5項目を見る → ③チャットに「OK」または「直す: ○○」を送る → ④AIが公開（または修正）→ ⑤公開後のURLを、AIが報告する。

## 5項目（上から順に。1項目30秒）
1. **画像を見る**: 見出しと数字が目に入るか。違和感のある文はないか
2. **数字**: 売上・記事数・費用（Claudeの月額プラン3,000円のみ）が、今の事実と合っているか
3. **名前**: 本名、顔、学校名、メール、アカウント名（keita…）が出ていないか。出ていたらその箇所を教える
4. **失敗カード**: 書いてある内容が事実どおりか。公開してよいか
5. **約束**: 「稼げる」と読める文がないか。AI利用を隠していないか

返事の型: 「OK」／「直す: ○○（場所と直し方）」／「止める」
- 「OK」だけで公開してよい。AIが確信できていない点は、AIが毎回、要確認の文書に書く
- 公開後に間違いが分かったら、すぐ直せる（取り消しにくいのは、個人情報と名前の露出。だから3を必ず見る）
