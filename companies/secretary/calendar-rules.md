## バーレモネード1号店カレンダーの判定
1. タイトルに「鈴木啓太」「けいた」「けーた」が入っている → **Keitaの予定**
2. **タイトルが「鈴木啓太」だけ → 出勤（シフト）。** バーへの【移動】（**行きだけ**）を入れる
3. 「出勤確認報告あげる」（毎日15:00） → **Keitaのタスク。必ずやる。** 他の作業枠を重ねない
4. ミーティング系（MTG・ミーティング・会議・面談・定例・予定合わせ・週次ミーティング準備）
   - 個人名が入っていない → **参加**
   - Keitaの名前が入っている → **参加**
   - **Keita以外の個人名が入っている → Keitaの予定ではない（無視）**
5. それ以外（他のスタッフ名だけのシフト、他人の作業枠・タスク） → 他人の予定。無視する
6. 「期限 けいた」が付いたもの → Keitaのタスク（期限つき）。`tasks.md` に載せる

## 絶対に守ること
- **バーレモネード1号店のカレンダーは、読むだけ。作成・変更・削除をしない**（変更はKeitaがする）
- 予定がぶつかったら、秘書が勝手に決めずに**毎回Keitaに投げ返す**（仮の対応案を添える）
- 店カレンダーの期限タスクは**終日の締め切り**として扱う（例: 「期限 けいた」11/12 → 11/12中）

## 移動の組み方
- 到着は**10分前**
- 移動中にオンラインの予定が重なる場合は、**先に移動して、着いた先でオンラインに出る**（オンラインの前に移動を終える）
- 前の予定から次の予定へは直行（間が「帰り＋行き＋60分」より長いときだけ柏に帰る）
- シフトの後の帰りは入れない（Keitaの指示で行きだけ）

## 予定の書き方（2026-11-07 決定）
### 作業の予定（タスクをやる時間）
- タイトル: `内容→相手`（相手がいなければ内容だけ。短く。15文字前後）
- 色＝事業: SBO 7（ピーコック）／レモネード 5（バナナ）／バイト 2（セージ）／個人 8（グラファイト）／ガクコエ 3（グレープ）／ビジコン 9（ブルーベリー）。新しい事業は空いている色を割り当て、ここに追記する
- 同じ時間に2件入れない。1件ずつ並べる
### 締切・中間報告（終日の予定）
- 締切: `🔴〆 内容→相手`、色 11（トマト）、終日、「空き時間」扱い（予定をふさがない）
- 中間報告: `🟠中間 内容→相手`、色 6（ミカン）、終日、「空き時間」扱い。**同じ日に3件以上あるときは1件にまとめる**（`🟠中間 9件（提案資料・半年計画ほか）`、中身はメモ欄に一覧）
- 作業の予定には絵文字を付けない（🔴🟠があれば期限、なければやる作業）
- 店カレンダーにすでにある期限（「期限 けいた」）は重複して入れない
### メモ欄（全部の予定で詳しく書く）
```
K-12｜SBO｜5分｜中間 -／締切 11/10
■目的:
■やること:（手順を番号で）
■準備済み:（秘書が先にやったこと）
■完了の条件:
■注意:（あれば）
■送る文面:（返信・連絡なら全文）
■終わったら: 秘書に「K-12 済」
```
移動の予定のメモ欄: 目的（どの予定に行くか）／経路と所要時間（推定かどうか）／着いたらやること／住所／経路確認のリンク

## 議事録からタスクにする（2026-11-07 決定）
1. 拾う: 夜の確認の前に、その日届いたGeminiの自動メモを確認。「議事録反映して」と言われたときも
2. 抜き出す: 誰が・何を・いつまでに
3. 仕分け: Keita（鈴木啓太／けいた／けーた）が担当 → Keitaのタスク。他の人が担当でKeitaが結果を待つもの → 状態「相手待ち」。担当・期限・事業が分からないもの → **推測せずに聞く**
4. **必ずチャットで一覧を出して確認してから**シートに書く（期間を区切らず、毎回）
5. 期限が書いていない宿題 → 次に同じ会議がある日の前日を案として出す（定例でなければ7日後）。これも確認の一覧に含める
6. 備考に「会議名＋日付」、リンクに議事録のURL。同じ会議から同じ宿題が出ていたら足さない
