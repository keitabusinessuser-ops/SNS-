# 秘書システム（v1.0 / 2026-11-07）

**公開禁止。** Keitaの予定・連絡・タスクを1か所で管理する。事業（C社・メディア社）も私用も、Keitaの時間を使うものは全部ここに入れる。

## 流れ（Keitaがやるのは①と⑤だけ）
```
①Keitaが投げる（チャットに雑に。1行でOK）
   ↓
②秘書が仕分け … tasks.md に登録（期限・工数・優先度・AIが先にやれる部分）
   ↓
③秘書が下ごしらえ … 調べ物・下書き・返信案（Gmail下書き）まで先に作る
   ↓
④秘書が時間を確保 … Googleカレンダーに【秘書】ブロックを入れる
   ↓
⑤Keitaが実行・判断 … 終わったら「K-03 済」と一言
```
朝夜の報告（`companies/reports/`）の先頭に、期限が近いもの（シートの黄・橙・赤）を載せる。

## ルール（仕組みで回すための制約）
1. **件数で絞らない**（2026-11-07 Keita指示）。期限と工数で並べ、期限に間に合わないものは早めに投げ返す
2. **14日動かないタスクは「捨てる候補」に自動で落とす。** Keitaは「捨てる／残す」の一言だけ
3. **工数は「Keitaの手が要る分」だけ数える。** AIが先にやれる部分は分けて書き、先に終わらせる
4. **返信は下書きまで。送信はKeita。** 送信・投稿・規約同意・支払いはKeita本人（CLAUDE.md の承認ゲート）
5. **カレンダーに入れるのは本人のカレンダーのみ。** 他人を招待しない。【秘書】が付いた予定は、不要ならKeitaが消してよい
6. **repoに第三者の実名・連絡先・金額・口座情報を書かない。** 属性＋イニシャル＋Gmailリンクで管理する（漏洩ゲート）
