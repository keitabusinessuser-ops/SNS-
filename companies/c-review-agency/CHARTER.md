# C社: 口コミ返信・MEO運用代行

## Why
- 口コミ返信が止まっている店は多いと思われる（仮説・未検証）。返信はAIで自動化しやすく、店舗数が増えても1店あたりの作業が増えにくい
- 月額ストック型で、1ヶ月目から収益が立つ可能性がある

## What
- 対象: 美容室（仮置き）。全国。リモート完結
- 商品（2プラン。価格は仮説）
  - ライト 月4,980円: 返信案を毎週メール/LINEで届ける。投稿は店主
  - フル 月9,800円: こちらが投稿。Googleビジネスプロフィール API の利用可否が確定してから提供（未確認）
- 目標: 月20万 = ライト40店 or フル20店

## How
1. リスト: 口コミ数が多く返信がほぼ無い店を抽出（手作業 or Places API。スクレイピングはしない）
2. デモ: 直近の口コミ3件への返信案を画像化
3. 送信: 公表メールアドレス/問い合わせフォーム/Instagram DM。週1回まとめてKeita承認後に送信
4. 契約: Stripe 決済リンク（初月無料→翌月課金）。面談は原則なし
5. 紹介パートナー: 税理士・ディーラー・予約/POS代理店に成果報酬20〜50%（実績3〜5件取得後に着手）

## 法務・規約（先回り）
- 特定電子メール法: 公表アドレス宛・事業関連の広告は同意不要だが、送信者名の表示とオプトアウト手段は必須。断られたら再送しない（要最終確認）
- Google規約: 口コミの自作・投稿誘導はしない。扱うのは返信のみ。権限はオーナーからの管理者招待
- ステマ規制（景表法）に注意
- 守秘: 店舗のアカウント情報は最小権限で扱う

## KPI（4週時点で判定）
| 指標 | 目標（仮説） |
|---|---|
| デモ送付数 | 30店以上 |
| 反応率 | 20%以上 |
| 契約数 | 3店 |
| 月額売上 | 3万円〜 |
| Keita稼働 | 週3〜4時間（立ち上げ期） → 週2〜3時間（軌道後） |
