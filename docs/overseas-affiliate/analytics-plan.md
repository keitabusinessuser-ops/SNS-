# データ分析の運用 v0.1（2026-10-04）

## Claudeができること・できないこと
| | 内容 |
|---|---|
| できる | スクショや書き出したCSVを読み取って集計する／テストの合格・撤退の判定／伸びたテーマを見つけて次の台本に反映する |
| できない | Instagramに直接ログインしてデータを取ってくること（接続する仕組みがなく、この環境からはMetaのサーバーにも接続できない可能性が高い） |
| 将来 | 段階2（公式API）にすれば自動で取得できる。ただしアクセストークンを預けるので、Keitaの承認が必要 |

## データの渡し方（どちらか）
| 方法 | 手間 | 内容 |
|---|---|---|
| A. スクショ（今はこれ） | 1本30秒 | リールの「インサイトを見る」画面をスクショして送る。Claudeが数字を読み取って `content/analytics/reels-log.csv` に記録する |
| B. CSVの書き出し（5本以上たまったら） | 月1回5分 | パソコンでMeta Business Suite →「インサイト」→「コンテンツ」→ 期間を指定 →「エクスポート」→「CSVデータとしてエクスポート」。ファイルを送る（[参考](https://inno-mark.jp/datavista/blog/instagram-mbs-csv/)） |

※インサイトで見られるのは過去90日分まで。月1回は記録しておく。

## 見る数字と判定基準（T2テスト）
| 数字 | 意味 | 合格ライン |
|---|---|---|
| 平均再生数 | 届いた量 | 1,000回 |
| （保存数＋シェア数）÷ 再生数 | 役に立った度合い（非フォロワーへの拡散に効く） | 2% |
| フォロー数 ÷ 再生数 | アカウントへの興味 | 参考値 |
| 撤退ライン | 10本の平均再生が300回未満 | → 形式を変えるか、パターンCのテストに切り替える |

集計は `python3 tools/analyze_reels.py` で行う。
