# 比較検証：「インスタ→公式LINE→自社商品」型 vs 海外アフィリエイト v0.1

検証の対象：SNSで出回っている7ステップの手法（インスタ開設 → 痛みの深いジャンル → 伸びているリール30本の分析 → 毎日リール60日 → 公式LINEでリスト化 → 4,980〜29,800円の商品を販売 → 自動化して年内に月100万円）。

---

## 1. 前提整理：手法の主張を事実と照らし合わせる

| 主張 | 判定 | 根拠 |
|---|---|---|
| ➎「フォロワーは数字、リストが財産」 | ✅ 正しい | プラットフォームのアルゴリズムに左右されない資産になる。海外アフィの計画でもメールリストを最優先にしている |
| ➐ 売れた流れを記録して自動化 | ✅ 正しい | 仕組み化の考え方はこちらの方針と同じ |
| ➊ 今週始める | ✅ 方向性は正しい | 検証を2週間もかけるのは長すぎる。1週間に縮めるべき |
| ➏「リストの1割が買う」 | ❌ 楽観的すぎる | デジタル商品はリストの1〜2%が買うのが目安。メール全体の平均成約率は0.32%（[MailerLite](https://www.mailerlite.com/blog/email-marketing-conversion-rate)）。1割は5〜10倍の過大見積もり |
| 「年内に月100万円」 | ❌ 根拠なし | 今日は10/4で、残り約3ヶ月。下の試算のとおり、新しいアカウントでは現実的でない。生き残った人の例だけを見ている |
| ➋ 恋愛・お金・人間関係を選ぶ | ⚠️ 法的リスクと競合の多さ | SNSきっかけの副業・もうけ話トラブルは増加中で、2023年度は相談の63.4%がSNSきっかけ（[国民生活センター](https://www.kokusen.go.jp/news/data/n-20240904_1.html)）。「お金」の分野で投資の助言をすると金融商品取引法上の登録が必要になる可能性がある（要確認）。どのジャンルも参入者が最も多い |
| 公式LINEは無料で回せる | ⚠️ 無料なのは月200通まで | ライトプラン（月5,000円）で5,000通、スタンダード（月15,000円）で30,000通（[LINEヤフー for Business](https://www.lycbiz.com/jp/news/line-official-account/20221031/)） |
| 1日30分で足りる | ⚠️ 投稿だけなら | 商品の制作、販売ページ、特定商取引法に基づく表記、問い合わせ対応が別にかかる |

※この投稿自体が「リストを集めて商品を売る」流れの入口になっている可能性が高い。手法そのものより、この人の講座を売るための投稿として読むのが妥当。

## 2. 試算：月100万円に必要な量（仮説）

| | インスタ×LINE型 | 海外アフィ（現在の計画） |
|---|---|---|
| 1人あたりの売上 | 約9,800円（商品の平均単価） | 約$5（≒750円、$1=150円で仮定） |
| 粗利率 | 約90%（デジタル商品） | 100%（報酬そのもの）。ただし単価が低い |
| 月100万円に必要な購入者数 | 約100人 | 約1,300件 |
| 必要なリスト／流入 | 購入率2%なら約5,000人／**投稿の主張どおり1割なら約1,000人** | 約26万PV |
| 必要なフォロワー（LINE登録率5%と仮定） | 約10万人（購入率2%）／約2万人（1割） | — |

→ **1人あたりの単価は約13倍の差があり、インスタ×LINE型が構造的に有利。** ただし、成り立つかどうかはアカウントが伸びるかどうかに強く依存し、ばらつきが大きい。

## 4. 結論：D を採用（提案・未決定）

**手法の「型」（リスト化＋自社商品＋仕組み化）は採用し、「ジャンル」は採用しない。**
海外アフィの計画にリストと自社商品を組み込み、単価の低さという最大の弱点を補う。

- 入口：英語のInstagramリール／Pinterest／検索 → 無料の「Japan Trip Checklist」でメールアドレスを集める（英語圏ではLINEよりメールが主流）
- 自社商品：「日数別のモデルルート＋予約チェックリスト」などのデジタル商品（$19〜49）。商品の中にeSIM・ツアーのアフィリエイトリンクを入れて二重に稼ぐ
- 試算（仮説）：月12万PV × 登録率2% ＝ 月2,400人がリストに入る → 商品購入2%で月48件 × $29 ＝ $1,392 ＋ アフィ$3,000 ＝ **月約$4,400**（アフィのみの約1.5倍）

### 判断が逆転する条件
- **「今年中に円で現金を作る」が最優先なら C**（父親メディア×LINE×自社商品）。投稿の手法と同じ構造を、競合が少なく、Keitaがすでに構想しているジャンルでやる形。ただし医療・心理の監修が前提で、これがないと売る商品を作れない。

### 普通はやらないが勝てる可能性のある案
**英語のInstagramリールで、Keitaが撮った日本の映像だけを使う。** 台本と字幕はAIが作り、映像は本物。英語圏の発信者は日本に住んでいないので、同じ量の一次映像は作れない。投稿の手法（➌型の分析、➍毎日投稿）はこの形にそのまま使える。

## 5. リスクと対策
| リスク | 対策 |
|---|---|
| 自社商品を販売すると、特定商取引法に基づく表記（氏名・住所・電話番号）が必要 | 個人での表記方法を確認する（要確認）。バーチャルオフィスの利用も検討 |
| 英語圏の消費者保護（返金・表示） | 決済サービス（Gumroad／Stripe等）の規約に沿った返金ポリシーを用意する |
| リールが伸びない | 60日続けて判断する（投稿の➍は正しい）。ただし入口は検索とPinterestにも分けておく |
