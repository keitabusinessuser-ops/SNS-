# ブランド名・アカウント名の候補 v0.1（2026-10-04）

## 決める条件
1. 個人名を出さない（情報漏洩対策）
2. 公式機関と誤解される名前にしない（「Official」「JR」「Suica」「Narita Airport」など他社の商標・施設名は使わない）
3. 東京以外にも広げられる（大阪・京都版の商品につなげる）
4. Etsyのショップ名のルールに合う：4〜20文字、英数字のみ、スペース・記号なし（[ShopFoundry](https://www.shopfoundry.app/etsy-shop-name-character-limit)）
5. 商品名「First 72 Hours in Tokyo」と一致させる
