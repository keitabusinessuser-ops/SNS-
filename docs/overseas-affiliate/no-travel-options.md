# パターンDの再設計：旅行に行かずに回す方法 v0.1（2026-10-04）

## 1. 前提整理
- Keitaの行動範囲：**千葉県と東京の行き来**。旅行にはほとんど行かない
- → 仮説D5「日本各地の現地映像を継続して撮れる」は **❌ 否定**
- パターンD（海外アフィ×リスト×自社商品）の方針自体は維持する（Keitaが賛成）

### この制約を見直した結果：千葉と東京は「弱み」ではなく「訪日客が最も通る場所」

## 2. 仮説：旅行に行かずに回す5つの方法

| 案 | 中身 | 撮影の負担 | オリジナル性（Instagramの評価） | 判定 |
|---|---|---|---|---|
| **D-1 生活圏に特化** | 「東京に着いてから最初の72時間」に絞る：成田・羽田→都内の移動、Suica・eSIMの設定、券売機、コンビニ、ディズニー（千葉県浦安市） | 通勤のついでにスマホで撮る（週15分） | ◎ 自分で撮った映像 | **採用** |
| **D-2 撮影ゼロのデータ・図解型** | 画面録画・地図アニメ・料金比較表・AIの音声で作るリール。日本語の公式発表を英語で速報 | なし | ○ 自分で作った図解なのでオリジナル | **採用** |
| D-3 寄稿者・購入者から映像を集める | 日本在住の外国人に成約報酬を分ける／購入者に旅行写真の提供を依頼 | なし | ◎ | Phase 3から（契約が必要） |
| D-4 ストック映像・AIで作った風景 | 素材サイトの映像やAI生成の映像を使う | なし | ✕ 他の人と同じ素材は複製と判定されやすい。AIの風景は旅行者を誤解させる | **却下** |
| D-5 成田の乗り継ぎに特化 | 成田で長時間の乗り継ぎがある人向け（成田山・参道・空港周辺） | 年に数回、成田で撮る | ◎ | **普通はやらないが勝てる可能性のある案**としてD-1に含める |

## 3. 採用案：D-1 × D-2 「Tokyo & Narita 到着専門」

### 設計
- **ポジション**：「日本全国の旅行ガイド」はやめる。**「日本に着いてから最初の72時間（成田・羽田→東京）」の専門家**になる
- **制作の比率**：80%は撮影なし（D-2：図解・画面録画・比較表）、20%は通勤ついでのスマホ映像（D-1：駅・券売機・コンビニ・空港アクセス）
- **Keitaの作業**：週15分の撮影＋週1回の承認だけ。撮る場所は普段通る駅・コンビニ・電車の中

### 収益の導線（すべてドル建てで受け取れる）
| 到着後の悩み | 紹介する商品 |
|---|---|
| 空港から都内へどう行く？ | 京成スカイライナー・成田エクスプレスの事前購入（Klook等） |
| スマホがつながらない | eSIM（Airalo 10%、Klook eSIM 20%） |
| 乗り継ぎで時間がある | 成田の乗り継ぎツアー（GetYourGuide） |
| 東京で何をする？ | ディズニーのチケット、東京のツアー |
| 最初の3日間を失敗したくない | **自社商品「First 72 Hours in Tokyo」到着キット（$9〜14）** |

### 実地テストT1の変更
- 変更前：「日本7日間モデルルート」
- **変更後：「First 72 Hours in Tokyo — 到着キット（成田・羽田→ホテル、Suica・eSIMの設定、東京3日間ルート）」**
- 理由：Keitaの生活圏だけで内容を検証・更新できる。範囲が狭い分、全国ガイドの出品者と差別化しやすい

## 4. 検証方法
| 仮説 | 検証のやり方 | 合格ライン |
|---|---|---|
| 撮影なしの図解リールでも伸びる | D-2のリールを5本投稿 | 平均再生1,000回 |
| 通勤ついでの映像は図解より伸びる | D-1のリールを5本投稿して比較 | D-2より保存・送信が多い |
| 「到着」に絞った商品が売れる | Etsyに出品 | 14日で閲覧500回 or 販売1件 |

## 5. リスクと対策
| リスク | 対策 |
|---|---|
| 駅の構内での撮影には事業者の許可が必要な場合がある | 収益目的の撮影は、各鉄道会社の撮影ルールを確認する（要確認）。確認できるまでは駅の外・公共の場所・画面録画を中心にする |
| 映り込んだ人の肖像権・プライバシー | 人の顔はぼかす。顔が判別できない構図で撮る |
| 情報が古くなる（Suicaのように頻繁に変わる） | A4 データ鮮度管理が公式発表を毎週確認し、商品と投稿に「最終確認日」を表示する |
| 範囲が狭すぎて伸びしろが小さい | 東京で再現できたら、大阪・京都版は寄稿者（D-3）で作る |

## 6. 追記（2026-10-04）：成田にも行かない前提への修正
- Keitaは成田にもほとんど行かない → **成田での撮影はしない**。D-5（乗り継ぎ特化）は、地図・路線図・公式情報だけで作る「情報型」に変更する
- **写真・映像は必須ではない。** 撮影なしで「オリジナル」を出す方法：
  1. 自作の図解・比較表・計算ツール（D-2）
  2. 日本語の公式発表を最初に英語化する速さ（情報の差）
  3. **日本語での確認代行**：鉄道会社・施設に日本語で問い合わせて確かめた情報を「Verified in Japanese by a local」として出す（外国人の発信者にはできない。普通はやらないが勝てる可能性のある案）
  4. 商品画像はCanvaで作る商品の見本画像（モックアップ）で足りる
- 通勤中の映像は「あれば使う」程度の補助に下げる
