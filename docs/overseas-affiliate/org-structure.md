# 海外アフィリエイト事業部 — 役割設計 v0.1

`business-plan.md` の事業（訪日旅行者向けの英語メディア＋計算ツール）を運営するために必要な役割の一覧。
**原則：人がやるのは「AIにはできない・やらせてはいけない」仕事だけ。それ以外はAIエージェントと定期実行で回す。**

---

## 1. 設計の考え方

1. **AIにやらせてはいけない仕事を先に切り出す** → 公開の承認、実地の写真・体験、本人確認が必要な契約、税務判断、外部へ送信する操作。これがKeitaの仕事になる。
2. **収益が止まる箇所に専任を置く** → リンク切れ、ASPのプログラム終了、Googleのペナルティ、アカウント停止。普通は担当を置かないが、ここが止まると売上がゼロになる。
3. **全役割を最初から動かさない** → フェーズごとに起動する（第5章）。今はPhase 0なので、動かすのは4役割だけ。

## 4. 人とAIの線引き

| 人しかやれない（やらせてはいけない） | 理由 |
|---|---|
| 公開の承認 | 外部への公開にあたる。量産ペナルティと誤情報への最後の防波堤 |
| 現地の写真・体験 | AIでは作れない。作れば規約違反と信用の毀損につながる |
| ASP・金融口座の契約、本人確認 | 本人確認は代わりにできない。アカウントが停止されると収益がゼロになる |
| 税務の最終判断 | 専門家の領域 |

それ以外（調査・執筆・開発・配信・集計・監視）はすべてAIが担当する。

## 7. 普通はやらないが勝てる可能性のある案：寄稿者をレベニューシェアで集める
- B5 現地取材がこの事業のボトルネック（Keita 1人では取材できるエリアに限界がある）。
- 日本在住の外国人（ガイド・留学生・ブロガー）に、**固定費ゼロ・成約報酬の一部をシェア**する形で、写真と体験メモだけを寄稿してもらう。文章化はAIがやる。
- 効果：一次情報が全国に広がる／英語ネイティブの監修が入る／人を雇わずに取材力が伸びる。
- 注意：契約書が必要（著作権の譲渡と利用範囲、報酬の計算方法）。海外への支払いはWise等で行う。寄稿者のブログ等との利益相反ルールも必要。**Phase 3から**。

## 8. 実装方法（Phase 1で着手）
- 各AI役割は Claude Code のサブエージェント（`.claude/agents/<役割>.md`）として定義する。
- 毎日・毎週の作業は Routines（定期実行）で自動起動する。
- 成果物はこのリポジトリに保存し、公開前の承認はPRのレビューで行う（＝Keitaの承認はPRをマージするだけ）。
